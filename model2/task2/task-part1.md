# Task 2, part 1

## Specification of Operation

The operation `RemoveUser[net0, net1, u]` constrains `net1` to be the network state after removing an existing user `u` from `net0`, in a way that preserves the invariant. If the user `u` owns any contents `c`, those contents `c` should be removed. If the removed contents `c` have comments `c'` associated with them, the comments `c'` should be removed as well.
